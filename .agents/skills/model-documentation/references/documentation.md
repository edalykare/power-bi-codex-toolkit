# Documentation scope

Markdown output lists tables, columns, measures and relationship endpoints. It
escapes pipe characters and HTML-like text from metadata. JSON inventory also includes
recognized declarations, properties and expressions. Neither output executes DAX,
M, SQL or notebooks. Paths reflect local source locations and may need redaction.

Use an authorized engine separately to verify data types, runtime dependencies,
security behavior and actual refresh outcomes. Generated text is an inventory, not a
certified data dictionary or proof of governance compliance.
