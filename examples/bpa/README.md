# BPA rule examples

`metadata-rules.json` contains two original Tabular Editor Dynamic LINQ examples
for measure descriptions and static format strings. No community rule pack was
copied. The local Python checker uses its own metadata checks; it does not execute
these rule expressions.

Use a compatible installed Tabular Editor to validate rule syntax/scope and run
analysis against a disposable local model. Dynamic format strings may make a static
format rule inappropriate. The examples are not a production rule policy and have
not been evaluated by a BPA engine in this environment. See the
[BPA skill reference](../../.agents/skills/model-audit/references/bpa.md).
